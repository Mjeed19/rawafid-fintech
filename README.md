## 📖 نبذة عن المشروع

**روافد فنتك** هو موقع صفحة واحدة (Landing Page) يعمل كمنصة رعاية رسمية لمعرض التقنية المالية الأكاديمي في المملكة العربية السعودية.

يستهدف الموقع **شركات الفنتك والبنوك والجهات الحكومية** الراغبة في رعاية الفعالية أو المشاركة فيها، ويعرض باقات الرعاية بتفاصيلها الكاملة ويتيح التواصل المباشر مع الفريق المنظم.

## 🚀 تشغيل المشروع محلياً

> لا يحتاج أي تثبيت أو build system — Python فقط!

```bash

# 2. شغّل السيرفر

# 3. افتح في المتصفح
# http://localhost:5000
```
